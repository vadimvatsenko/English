# English Trainer

Приложение-тренажер для изучения английского языка.

## Основные возможности
*   Интерактивное консольное меню с поддержкой вертикальной прокрутки.
*   Система уровней сложности (A0, A1, и др.).
*   Практика неправильных глаголов и лексики.
*   Учет статистики прогресса пользователя.
*   Авторизация и сохранение сессии.

## Управление
*   Навигация по меню: используйте клавиши **Стрелка вверх** и **Стрелка вниз**.
*   Выбор пункта: клавиша **Enter**.
